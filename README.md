# Spotify Data Pipeline & API

## Description
An ETL pipeline and REST API built in Python to process, store, and query personal Spotify listening history data.

## Architecture (Pending)
- **Extraction & Transformation:** Python
- **Storage:** SQLite / PostgreSQL
- **API:** FastAPI

## Project Structure
- `data/`: Raw and processed data (excluded from version control for privacy).
- `src/`: ETL logic and API endpoints.
- `tests/`: Unit tests and data quality validations.
